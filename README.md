# HDR Lab

Лабораторная работа на Go. Восстанавливает HDR-карту методом Дебевека–Малика по трём снимкам с разной выдержкой. Для просмотра программа применяет экспоненциальное тональное отображение и гамма-коррекцию.

## Запуск

Требуется Go 1.24.5 или новее. Снимки для примера находятся в input. Для другой серии укажи соответствующие выдержки в main.go.

```powershell
go run .
```

Введи lambda (например, 10000) и размер квадратной сетки (например, 16). Программа сохраняет HDR-карту в output/result.hdr, а изображение для просмотра — в result.png.

## Сравнение с OpenCV

```powershell
go run . -ssim result.png output/opencv_matched_result.png
```

SSIM сравнивает изображения после тонального отображения в градациях серого.
