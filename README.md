# HDR Lab

Лабораторная работа на Go. Восстанавливает HDR-карту методом Дебевека–Малика по трём снимкам с разной выдержкой. Для просмотра программа применяет экспоненциальное тональное отображение и гамма-коррекцию.

## Запуск

Требуется Go 1.24.5 или новее. Снимки для примера находятся в input. Программа принимает от трёх снимков одинакового размера. Пути и выдержки вводятся в терминале.

```powershell
go run .
```

Введи lambda (например, 10000), количество снимков, путь и выдержку каждого кадра, размер сетки (например, 16) и scale. Для серии из input укажи input/dark.jpg с выдержкой 1/750, input/normal.jpg с 1/180 и input/bright.jpg с 1/45. Для этой серии попробуй scale от 0.001 до 0.003. Для другой серии подбери значение по результату: больше scale — светлее изображение. Программа сохраняет HDR-карту в output/result.hdr, а изображение для просмотра — в result.png.

## Сравнение с OpenCV

```powershell
go run . -ssim result.png output/opencv_matched_result.png
```

SSIM сравнивает изображения после тонального отображения в градациях серого.
